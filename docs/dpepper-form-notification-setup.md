# Dペッパー 履歴共有メール通知 セットアップ手順

最終更新：2026-06-13

---

## 概要

Dペッパーの「この相談をDa-isに送る」から共有すると、Googleフォームに回答が記録されます。  
このApps Scriptを設定すると、フォームに回答が届くたびにお店用Gmailへ通知メールが自動送信されます。

---

## 設定手順

### 1. Googleフォームの回答先スプレッドシートを開く

1. [Googleフォーム](https://docs.google.com/forms/) を開く
2. Dペッパー共有フォームを選択
3. 上部「回答」タブをクリック
4. 右上のスプレッドシートアイコン（「スプレッドシートで表示」）をクリック  
   → 回答が記録されているGoogleスプレッドシートが開く

---

### 2. Apps Scriptエディタを開く

1. スプレッドシートの上部メニュー「拡張機能」→「Apps Script」をクリック  
   → Apps Scriptエディタが新しいタブで開く

---

### 3. スクリプトを貼り付ける

1. エディタ内の既存コードをすべて削除する  
   （`function myFunction() {}` のようなデフォルトコードが入っている場合は削除）
2. リポジトリの `docs/dpepper-form-notification.gs` の内容をすべてコピーする
3. エディタに貼り付ける

---

### 4. お店用メールアドレスを設定する

スクリプト冒頭の定数を編集してください：

```javascript
const SHOP_EMAIL = 'ここにお店用メールアドレスを入れる';
```

↓ 例：

```javascript
const SHOP_EMAIL = 'dais.hair@gmail.com';
```

> **注意：** `SHOP_EMAIL` を設定しないとメールは送信されません。  
> スクリプトのログに `SHOP_EMAIL が設定されていません` というエラーが出ます。

---

### 5. スクリプトを保存する

エディタ上部の「保存」アイコン（フロッピーディスク）をクリック、  
またはキーボードショートカット `Ctrl+S`（Mac: `⌘+S`）で保存する。

---

### 6. トリガーを追加する

1. Apps Scriptエディタの左側メニューから「トリガー」（時計アイコン）をクリック
2. 右下の「＋トリガーを追加」をクリック
3. 以下のように設定する：

   | 項目 | 設定値 |
   |---|---|
   | 実行する関数 | `onFormSubmit` |
   | 実行するデプロイ | `Head` |
   | イベントのソース | `スプレッドシートから` |
   | イベントの種類 | `フォーム送信時` |
   | エラー通知設定 | 任意（「毎日通知」推奨） |

4. 「保存」をクリック

---

### 7. 権限を許可する

1. 保存後、Googleアカウントの権限確認ダイアログが表示される
2. 「権限を確認」→ 使用するGoogleアカウントを選択
3. 「Da-isのメールにアクセスする」等の権限リストを確認
4. 「許可」をクリック

> **注意：** 「このアプリはGoogleで確認されていません」と表示される場合は、  
> 「詳細を表示」→「（プロジェクト名）に移動」をクリックして続行してください。  
> 自分のスプレッドシート用スクリプトのため安全です。

---

### 8. フォームの項目名を確認する（任意）

スクリプトが `e.namedValues` からフォーム項目を取得する際、  
候補名のリストで照合しています。

スプレッドシートの1行目（ヘッダー行）に表示されている項目名と、  
スクリプト内の候補名リストが一致していない場合は、スクリプトを調整してください。

```javascript
// 例：スプレッドシートの1行目が「お客様のご相談」だった場合
const consultText = getValue(namedValues, [
  'お客様のご相談',     // ← 実際の項目名を先頭に追加
  'ご相談内容', '相談内容', '相談文', 'ご相談文',
]);
```

スプレッドシートの実際の項目名は、  
**回答スプレッドシートの1行目（ヘッダー行）** で確認できます。

---

### 9. 動作テストをする

1. Dペッパーを開く
2. 何か相談を送信して履歴に保存する（または既存の履歴を使う）
3. 履歴詳細モーダルを開く
4. 「この相談をDa-isに送る」をタップ
5. 確認ダイアログで「共有フォームを開く」をタップ
6. 画面に「相談内容をDa-isに共有しました。」と表示されることを確認

7. Vercel Logsで以下のログを確認する：
   ```
   History share started | category: xxx | hasAiResponse: true
   History share ok
   ```

8. Googleフォームの回答スプレッドシートに1行追加されていることを確認する

9. Apps Scriptエディタの「実行数」メニューから `onFormSubmit` が実行されたことを確認する

10. `SHOP_EMAIL` に設定したGmailに通知メールが届いていることを確認する

---

## 送信されるメールのサンプル

**件名：** 【Dペッパー】相談内容が共有されました

**本文（抜粋）：**

```
【Dペッパー履歴共有】
送信日時：2026/06/13 15:42:00
相談日時：2026/06/10 11:30

カテゴリ：カラー相談
分類：ケア
お気に入り：⭐️ あり

── ご相談内容 ──────────────────────
最近カラーをしたのですが、色の落ちが早い気がして...

── Dペッパーの返答・メモ ─────────
色の落ちが気になる場合は...
```

## フォーム項目の候補名一覧（スクリプト内）

| フォーム内の役割 | 候補名（優先順） |
|---|---|
| ご相談内容 | `ご相談内容`, `相談内容`, `相談文`, `ご相談文` |
| Dペッパーの返答 | `Dペッパーの返答・メモ`, `Dペッパーの返答`, `AIの返答`, `AI返答` |
| 添付情報 | `添付情報`, `添付`, `attach`, `添付画像` |

実際の項目名がこのリストにない場合は、スクリプトの `getValue()` 呼び出し部分に追加してください。

---

## トラブルシューティング

| 症状 | 確認ポイント |
|---|---|
| メールが届かない | `SHOP_EMAIL` が正しいか確認。Apps Scriptの実行ログを確認。 |
| `SHOP_EMAIL が設定されていません` | スクリプト冒頭の `SHOP_EMAIL` 定数を編集して保存 |
| `onFormSubmit` が実行されない | トリガー設定でイベントの種類が「フォーム送信時」になっているか確認 |
| 項目が空欄になる | スプレッドシートの1行目の実際の項目名をスクリプトの候補名に追加 |
| 権限エラー | Apps Scriptの「サービス」で `MailApp` が有効か確認。権限を再許可する。 |
